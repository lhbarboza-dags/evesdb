Edit A Study

This feature allows curators, content managers, and admin to update/edit/correct studies in the database. This is to correct any mistakes committed in the data entry. And also, by default, all curated studies are not displayed and searchable. Content managers or admin need to approve studies first so that it would be viewable and searchable.

To Edit a study:

  1. Login to Sibol-eves database account. 
  2. Go to Data Management -> Study Entry -> View/Edit Study

  1. On the result panel, click the row of the desired study to edit. This will open a dialog box shown below. The first tab is for editing source information and the second tab is for editing the actual data.

a. Study Source Tab. Editing values for study sources is straight forward. 


b. Data Tab. This tab lets users edit data within a study. Click on the row to edit.


1. Add Site.  This button opens a dialog box and lets users add additional sites to a study.

2. Add Site Valuation. This button opens a dialog box to let users add additional valuations to that specific site.

3. Delete Site from a study. 

4. Delete valuation from site. 

5. Open Detail. Collapses and uncollapses detail panel for a specific site.


  1. Click Save to save changes, otherwise click Cancel to undo changes made

Dictionary or Controlled Vocabulary Management


Controlled Vocabulary is organized terms used to describe data on this website which is also used to query, retrieve and browse through contents and data easily and accurately. This vocabulary is managed only by users with a content manager or admin account and can be used for data entry by the curators.


Here are some of the controlled vocabulary for this website

  1. Available Study Info - Types of information available from the study (e.g., code documentation, data sets, maps or pictures, questionnaire or questions used, risk assessment or dose-response relationships, description of scenarios or classification schemes, tables)
  2. Beneficiary Unit - The unit used for beneficiaries for which the ES value estimate is reported (e.g., number of visitors/tourists, number of persons, number of households, etc.
  3. Climate - Type of climate in the study site
  4. Country - Name of country or countries where the valuation study was undertaken
  5. Currency - Currency of the reported monetary value (s)
  6. Document Type - The original format of the ES valuation study, e.g., published as an article in a journal, government or non-government report, working paper, conference paper, dissertation/thesis, chapter in a book, magazine, or book.
  7. Economic measure - Type of economic value measure estimated in the study (e.g., consumer surplus, cost of injury, price, willingness-to-pay, etc.)
  8. Ecosystem (Realm, Biome, EFG) - Classification of realm, biome, and EFG that is the subject of the value estimate based on the SEEA-EA Ecosystem Type Reference Classification based on the IUCN Global Ecosystem Typology (Keith et al., 2020, Table 3.2). 
  9. Protected Status - Adapted from the existing classifications of protection status in the Philippines (NIPAS Act 1992; E-NIPAS Act 2018) and internationally (https://www.iucn.org/theme/protected-areas/about/protected-area-categories)
  10. Scale - Text description of the scale of the study site over which the ecosystem that produces the service is measured. The scale is categorized into: local (municipal/provincial/state); sub-national (regional); national; or multi-country.
  11. Service (Ecosystem Service, Ecosystem Subservice) - Classification of the ecosystem service that is the subject of the value estimate based on the SEEA-EA Reference List of Selected Ecosystem Service (Table 6.3 of the UN-SEEA-EA: Final Draft (v.5 Feb. 2021)
  12. Site Attribute - Significant attributes of the study site(s) described in terms of environmental amenities which can include "access to clean air or clean water, or the quality of any other environmental good that may reduce adverse health effects for residents or increase their economic welfare. Environmental goods are typically non-market goods, including clean air, clean water, landscape, green transport infrastructure (footpaths, cycleways, greenways, etc.), public parks, urban parks, rivers, mountains, forests, and beaches." Field, Barry C.; Field, Martha K. (2017). Environmental Economics, An Introduction (7 ed.). McGraw-Hill. p. 145-147. ISBN 978-0-07-802189-3.
  13. Unit - Refers to the spatial unit of the reported monetary value (s) ( e.g., per hectare, per km2, per acre, total area, per kilometer, per mile, total length) or the temporal unit of the reported monetary value (e.g., per visit, per day, per month, per year, present value over multiple years) or a combination of spatial and temporal units (e.g., per hectare per year, per household per year).
  14. Value Type - Type of value generated by the study, e.g., a point estimate - annual mean, annual median, a range, a net present value, capital/stock value, marginal value, an annualized value, a one time payment or WTP value, or aggregate or total economic value.
